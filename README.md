# hxyfront-62010 潜水气瓶充填记录

给潜水店使用的气瓶充填前端系统，完整覆盖「登记 → 待充填队列 → 开始充填 → 结束充填签收 → 单瓶历史」作业流程，数据保存在浏览器 localStorage，刷新后状态保留。

## 作业流程与规则

1. **登记**：填写气瓶编号、容积、检验有效期、残压、目标压力（Trimix 可填氦含量），提交后进入待充填队列。
2. **开始充填**：
   - 检验有效期早于今天 → 拦截，在队列卡片上显示具体原因，气瓶留在队列，不产生任何状态变更。
   - 同一气瓶已有充填中任务 → 只提示已被占用（含单号），不产生第二条任务或半成品。
   - 校验通过后任务变为「充填中」。
3. **结束充填 / 签收**：必须填写实际压力、氧含量、充填方式、操作员；缺项或实际压力未达到目标压力均不能签收，防止不合格气瓶放行。同步给出混合气（O₂/N₂/He）比例提示与空气/高氧方式不符提醒。
4. **签收后**：任务移出待充填队列；在「气瓶历史记录」按编号可查该瓶全部单据及签收明细。
5. **持久化**：所有任务存于 localStorage（键 `dive-shop-fill-tasks-v1`），刷新页面状态保留。首次打开内置演示数据（含过期、临期、充填中、已签收样例）。

## 本地运行

```bash
npm install
npm run dev
```

开发端口：62010
